Feasibility bench

UpgradeProof

One dependency, one target version. Baseline, break, repair or abstain, then a patch only if the public tests and the hidden checks both pass.

Passing tests are not universal compatibility.

Rules in this repository were written with these fixtures. The repair rate is a feasibility result, not a score on unseen upgrades. Historical fixes elsewhere may also sit in a model's training data; these cases are newly authored and still not a contamination-free study.
